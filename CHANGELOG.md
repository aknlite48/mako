## [0.1.0] - 2026-10-18

Initial release.

### Added

- VS Code-style editor shell: title bar, activity bar, Explorer sidebar with
  git decorations and inline file/folder creation, tabs, status bar
- CodeMirror 6 editor with syntax highlighting (JS/TS, Python, Rust, HTML,
  CSS, JSON, Markdown), find, indentation guides
- Read-only Git Graph tab: colored commit lanes, ref chips, stashes,
  uncommitted-changes row, branch filtering, find, inline commit details
  with changed-file tree opening side-by-side diffs, multi-repo discovery
- Integrated terminal: real PTY, splits, tabs, shell integration with
  command decorations, maximize/restore
- Live file watching: explorer, editors, git decorations, status-bar branch,
  and graph refresh automatically on external changes
- Multiple independent windows (Cmd+Shift+N)
- Five themes: Dark+, Dark Modern, Light+, Monokai, Solarized Dark
